================================================================================

STEP 1: Install Dependencies
-----------------------------
cd /home/user/Business/formbackend-saas
./setup.sh

STEP 2: Configure Settings
---------------------------
Edit backend/.env and change these MINIMUM settings:

  JWT_SECRET=your-random-secret-key-change-this-to-something-random
  SMTP_USER=your-email@gmail.com
  SMTP_PASS=your-gmail-app-password

(For testing, you can skip Stripe setup initially)

STEP 3: Start the Application
------------------------------
./start.sh

This starts:
  - Backend API: http://localhost:3000
  - Frontend Dashboard: http://localhost:5173

STEP 4: Test It
---------------
1. Open http://localhost:5173
2. Click "Sign Up" and create an account
3. Create a form in the dashboard
4. Test the form submission endpoint
